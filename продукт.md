# Продукт Car2Me

Обновлено: 2026-11-09

Раздел «Решили» — назначение, с которым сверяем дизайн и гипотезы. Раздел «Предполагаем» доказательством не является. Гипотезу подтверждает только цифра в её папке `гипотезы`.

## Решили

Сервис для человека, который не разбирается в марках и знает, как ездит. Ему нужно сделать первый шаг: по своим параметрам выбрать модель. За сутки он получает короткий список моделей и честную цену «под ключ».

- В цену входят действующий утильсбор и все платежи.
- Предлагаем только модели, которые можно законно ввезти. Ограничения на вывоз, например из Кореи, проверяем.
