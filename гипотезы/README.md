# Гипотезы новой версии

Каждая гипотеза — отдельная папка рядом с `_образец`. В папке лежит `текст.md` по образцу.

`_образец` не публикуется и не считается проверкой.

`связи.md` — какие гипотезы делят человека, цифру «да» или страницу. Строка появляется вместе с гипотезой, если такое совпадение есть.

Назначение сервиса, с которым сверяется гипотеза, лежит в `продукт.md` в корне. В тексте гипотезы указывают номер допущения оттуда.

Страницы гипотез входят в новую версию сайта в этой же папке `D:\car2me`. Старый код в `D:\car2me-site` для них не используется. Пока в тексте гипотезы не написано «да», ссылку на неё не ставят в меню.
