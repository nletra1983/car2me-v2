# Новая версия Car2Me

Сервис подбора автомобиля: какая машина подходит и сколько она стоит «под ключ».

Эта папка — `D:\car2me`. Живой сайт https://car2me.ru/ пока показывает первую пробу из другой папки, `D:\car2me-site`.

Что уже настроено и чего пока нельзя делать — в `настройка.md`.

Эта памятка дополняется, когда в проекте появляется новая папка или важный файл.

## Что открывать

- `настройка.md` — что уже сделано и что делать дальше.
- `продукт.md` — назначение сервиса: что уже решили и что пока только предполагаем. Гипотезу подтверждает цифра в её папке, а не совпадение с этим файлом.
- `гипотезы` — тексты проверок. У каждой своей папки есть `текст.md`. Образец полей: `гипотезы\_образец\текст.md`. Таблица, какие проверки задевают друг друга: `гипотезы\связи.md`.
- `гипотезы\анкета-отчёт` — гипотеза «заполнят анкету и заплатят за отчёт»; страница `/anketa`.
- `Интервью` — план и записи разговоров.
- `Первая проба в сентябре` — описание, ревью и отчёты Метрики и Директа. Это архив.
- `src` — экраны новой версии. Цвета и шрифт — в `src\index.css`.
- `src\components\ui` — готовые детали оформления. Смысл сервиса сюда не пишем. Пока не используются на странице: `empty.tsx`, `scroll-area.tsx` (заготовки под будущие экраны).
- `src\components\landing` — общие части лендинга: шапка, кнопки, лист отчёта.
- `src\site\compare-mark.tsx` — галочки в таблице сравнения с Car2Me.
- `public` — картинки и файлы, которые сайт отдаёт как есть. SEO: `robots.txt`, `sitemap.xml`, редирект `form.html` на анкету. Подтверждение Яндекс.Вебмастера: `yandex_9e88854eaf015e88.html`.
- `src\lib\metrika.ts` — счётчик и цели Метрики (без передачи имени, телефона и почты). Юрдокументы: `offer.html`, `privacy.html`, `pd-consent.html`, стиль — `legal.css`. Реквизиты ООО «СМАРТ ЭФФЕКТ» в коде: `src\site\legal-entity.ts`. Фавикон: `favicon-32.png`, `favicon-512.png`, `apple-touch-icon.png`. Аватарки историй — в `public\stories\`. Картинки лендинга для публикации — в `public\images\` (пути в коде: `src\lib\site-images.ts`).
- `картинки` — исходники и дубликаты для редактирования; на живой странице используется копия из `public\images\`.
- `src\lib\site-images.ts` — единый список путей к картинкам лендинга.
- `src\site\legal-entity.ts` — реквизиты получателя платежа (не дублировать вручную в текстах).
- `проба-лендинга.html` — отдельная проба нового лендинга. Это не живой сайт и не экран в `src`.
- `промт-лендинга.md` — текст для Bolt: им собирается прототип лендинга, одна страница.
- `Пример отчёта Car2Me.pdf` — отчёт из прототипа Даши в нашем оформлении (лого, шрифт, цвета), контент прежний. Такой же файл лежит в `public\пример-отчёта.pdf`: его скачивает кнопка «Открыть пример целиком, PDF».
- `src\site\landing.tsx` — главная страница сайта.

## Как будет расти сайт

`src\pages` — один файл на экран: `home.tsx` (главная) и `anketa.tsx` (анкета, адрес `/anketa`).

Свой блок экрана, например шапка или карточка машины, ляжет в `src\components`.

Общие мелкие функции лежат в `src\lib`.

## Служебные файлы в корне

Их место — корень. Сборка ищет их только здесь. Обычно их не открывают.

- `package.json` — список библиотек и команды запуска сайта. Проверка лендинга в браузере: `npm run test:e2e` (нужен один раз `npx playwright install chromium`).
- `playwright.config.ts`, папка `e2e` — автоматическая проверка главных кнопок и ссылки на PDF.
- `package-lock.json` — точные версии этих библиотек.
- `index.html` — оболочка, которую открывает браузер.
- `vite.config.ts` — как собирается сайт.
- `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json` — настройки языка, на котором написаны экраны.
- `eslint.config.js` — проверка аккуратности кода.
- `.prettierrc` и `.prettierignore` — как выравнивается код и какие файлы не выравнивать.
- `components.json` — где лежат цвета и детали оформления.
- `.gitignore` — что не отправлять на GitHub.

Папка `node_modules` — скачанные библиотеки. Её не редактируют. Папка `dist` появляется после сборки: в ней готовый сайт для публикации.
